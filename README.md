# Bonjour Restaurant Website

A visually appealing and interactive website for "Bonjour", a fine-dining restaurant.

**Author:** Himadri Shekhar

See live at https://bonjour-6shv.onrender.com
Responsive part is under development, best viewed at 1080p display

## Description

This project is a frontend implementation of a restaurant website. It showcases a modern and elegant design with various sections providing information about the restaurant, its story, menu, and contact details. The website is built using plain HTML, CSS, and JavaScript, with a focus on smooth animations and a good user experience.

## Features

- **Welcome Animation:** A loading spinner and a welcome message that gracefully transitions to the main content.
- **Dynamic Navbar:** A navigation bar that changes its appearance and position on scroll.
- **Hero Section:** A full-screen hero section with an animated background that cycles through different images.
- **Interactive Menu:** A well-organized menu section displaying various dishes with images and descriptions.
- **Reservation Form:** A form for users to book a table.
- **Responsive Design:** The website is designed to be responsive and should adapt to different screen sizes (though further testing on various devices is recommended).

## File Structure

The project consists of the following files:

- `main.html`: The main HTML file that contains the structure of the website.
- `style.css`: The CSS file that styles the website.
- `script.js`: The JavaScript file that handles the animations and interactive features.
- **Image Files:** The project includes various image files (`.jpg`, `.png`, `.webp`, `.avif`) used for the background, logo, and menu items.

## Usage

To view the website, simply open the `main.html` file in a web browser.
